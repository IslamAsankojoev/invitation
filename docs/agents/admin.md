# Скрытый показ и админка

> Раздел контекста проекта для ИИ-ассистента. Корень и правила — [`AGENTS.md`](../../AGENTS.md); код — источник истины.

## Скрытый показ шаблонов и видео

- `/showcase/<ключ>` — список шаблонов (те же карточки, что на главной: `TemplateCard` с `href`, подпись «Открыть →»), `/showcase/<ключ>/<шаблон>` — приглашение целиком (`createFromTemplate`, без
  базы), как у гостя. Ключ — `SHOWCASE_KEY` в env (≥ 16 символов, `lib/showcase.ts`, сравнение за постоянное время);
  нет ключа или неверный — 404, страницы `noindex`. Режим `demo` (`InvitationPage demo` → `BlockContext.demo`):
  анкета не отправляется, а сразу благодарит; календарь — Google (у показа нет .ics).
- `npm run video -- <шаблон…|all> [--base http://localhost:3000] [--bg #hex] [--fullscreen]` (`scripts/template-video.mjs`),
  всё по замерам эталонного ролика: телефон в рамке на тёмном фоне, экран 513×1133 в кадре 1080×1920 (`SCREEN`, вёрстка
  390×862); конверт → след касания → печать → свайпы 1,15 с с путём 1−(1−t)^2,5 (резкий старт, плавный докат), пауза
  ~2,6 с (`T`). Куда листать — `nextScrollTarget`: целиком видные блоки пропускаются, первый видный не целиком встаёт к
  верху экрана (анимации не уходят за нижний край), блок выше экрана — по частям (`[data-reveal]`, `img`: к верху —
  первая обрезанная снизу часть), не дальше экрана; анкету не пропускает. `avoidCutPhotos`: в точке остановки фото
  (img, `[data-testid*=photo]`) не режется нижним краем — не долистываем (фото ещё за краем) или долистываем до его
  низа (иначе его анимация проигралась бы наполовину за краем). Всё меряется заново на каждом шаге — под любую структуру; анкета заполняется (имя по буквам, «Приду», +2,
  «Подтвердить»). Кадры — CDP screencast (~60 к/с) → ffmpeg (скругление экрана маской, рамка и фон — SVG через sharp),
  30 к/с H.264 в `videos/` (в .gitignore). `--fullscreen` — на весь кадр. По умолчанию без звука; `--audio` — с музыкой
  приглашения как у гостя (AAC 192 кбит/с): скрипт качает песню из `<audio data-testid="music">` (фрагмент и повтор —
  `data-start/data-end/data-loop`, их ставит InvitationPage) и собирает дорожку в ffmpeg: старт — момент нажатия на печать
  + 150 мс (`PLAY_LATENCY`), нарастание 2 с, затухание 1,5 с у конца фрагмента, повторы с нарастанием 0,8 с (константы
  как в music.tsx / musicFragment.ts), в конце ролика — затухание. Событие `playing` — только проверка, что песня
  заиграла: под нагрузкой screencast headless начинает играть ~на 1 с позже, этот сдвиг в ролик не переносим (часы
  кадров CDP и Node совпадают до мс). Права на песни из public/music не оформлены — публикация со звуком на владельце.

## Скрытая админка (`/admin/<ADMIN_KEY>`) — только локально

- Доступ — `ADMIN_KEY` в env (≥ 16 символов, `lib/admin.ts`, сравнение за постоянное время); на Vercel (`VERCEL` в env)
  админки нет даже с ключом: она пишет файлы проекта и запускает запись видео (Playwright + ffmpeg). Неверный ключ —
  404 (страницы `noindex`, API `api/admin/[key]/guard.ts`). Работает под `npm run dev`: сохранённый шаблон — JSON,
  который импортирует templates.ts, dev-сервер перечитывает его сам (под `next start` — только после сборки).
- **Шаблоны.** `templates` = шаблоны из кода (`baseTemplates`) + `src/lib/template-overrides.json`
  (`{ edited: { id: Template }, added: Template[], order?: id[], hidden?: id[] }`, `mergeTemplates`; битая правка пропускается с console.error).
  **Порядок** — перетаскиванием карточек за ручку «Перетащить шаблон «…»» (dnd-kit, `rectSortingStrategy`; замена —
  «Переместить раньше / позже» в меню «⋯»): сразу на экране, `PUT /api/admin/<ключ>/templates {order}` → `saveOrder`
  (все id ровно по разу, иначе 409; совпал с порядком «как в коде» — `order` убирается), ошибка — откат.
  `orderTemplates`: по `order`, не расставленные (новые копии, новые шаблоны в коде) — после, в своём порядке.
  Порядок действует везде, где `templates`: главная, показ, админка. Удалённая копия уходит из `order`.
  **Публикация** — переключатель «Опубликован» на карточке (`PATCH …/templates/<id> {published}` → `setPublished`,
  список `hidden` в файле правок; последний опубликованный скрыть нельзя — 409). `templates` — только опубликованные
  (главная, выбор шаблона в редакторе, шаблон по умолчанию); `allTemplates`/`findTemplate` — все (показ, админка, демо
  в seed, `guessTemplate`); `POST /api/invitations` берёт `findPublishedTemplate` — из скрытого 400, как неизвестный.
  Скрытый в админке — серый, с пометкой «Скрыт».
  Файл пишет только `lib/adminFiles.ts` (через временный файл + rename); корень — `ADMIN_ROOT` (в тестах — временная
  папка), иначе папка проекта. **Правки нужно закоммитить** — так они попадают на прод.
  «Редактировать» → `/admin/<ключ>/templates/<id>`: черновик — обычное приглашение со slug `tpl-<id>` (`ensureDraft`,
  автосохранение как всегда), в обычном `Editor` с `templateMode` (в шапке «← Админка», название, «Сохранить в шаблон»,
  меню «Показ сохранённого шаблона» / «Начать заново»). `templateFromInvitation` (lib/templateAdmin.ts): тема, песня (с фрагментом и повтором — `musicFragment`),
  все блоки по порядку → `layout` с `exact: true` (блок целиком — пустые поля не заполняются примером; без этого в JSON
  пропадали `subtitle: undefined` и т. п., и пример возвращал удалённый текст), имя/описание/`blocks` — от прежнего.
  Свои загрузки (`/uploads/…`, Supabase) копируются в `public/templates/<id>-<hash>.webp` со строкой в CREDITS.md
  (раздел «Загружено в админке», «уточняется»), черновик получает новые адреса (`replaced` → `replaceUrls`).
  Сохранили «как в коде» (`sameTemplate`) — правка удаляется, а не хранится. «Несохранённое» —
  `sameAsTemplate` (сравнение без id и без порядка ключей: jsonb их переставляет). В карточке: «Изменён» / «Новый»,
  меню — видео шаблона, показ, «Название и описание», «Дублировать» (`copyTemplate`: id «mocha-2»), «Сбросить
  изменения» / «Удалить шаблон» (вместе с черновиком).
- **Видео.** `lib/videoJobs.ts`: очередь в памяти сервера (globalThis), по одному ролику; `scripts/template-video.mjs`
  `<id> --base <адрес этого сайта> --name <файл> --bg <цвет> [--fullscreen]`; скрипт печатает `@stage open|record|encode`,
  `@progress 0–1`, `@file`; ошибка — строка «Error: …» из вывода. Нужен `SHOWCASE_KEY` (запись идёт через показ), иначе 409.
  Имена роликов: `<шаблон>--<дата_время>[--full][--sound].mp4` (`VIDEO_NAME`; старые `<шаблон>.mp4` тоже видны), папка
  `videos/`. «Со звуком» в окне записи (Switch, запоминается вместе с кадром и фоном) → `sound` → скрипт с `--audio`.
  Отдача — `videos/[name]` с Range (206; без него не перематывается, Safari не играет), поток читается по запросу
  (`Readable.toWeb` поверх fs ронял сервер «Controller is already closed», когда браузер обрывал загрузку). В админке:
  панель хода записи (прогресс: открытие 0–5 %, съёмка 5–90 % по доле пролистанного, склейка), опрос каждые 1,5 с,
  пока что-то пишется; «Записать все»; вкладка «Видео» (`#videos`) — кадр-превью (`#t=1`, без автозапуска), просмотр в
  окне, «Скачать» (`?download`), удаление с подтверждением, фильтр по шаблону. Окно записи запоминает кадр и фон
  (localStorage `admin-record-options`).
