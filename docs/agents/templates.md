# Шаблоны (`lib/templates.ts`, `components/templates/*`, `editor/TemplatePicker.tsx`)

> Раздел контекста проекта для ИИ-ассистента. Корень и правила — [`AGENTS.md`](../../AGENTS.md); код — источник истины.

- 18 шаблонов; у шаблона `events` (для каких событий — фильтр на главной, первое — событие нового приглашения; нет —
  свадьба) и `language`. Пять кыргызских и праздничных (2.5.0, свои векторы, без фото): `shyrdak` (Шырдак: войлок,
  кыз узатуу/свадьба), `ala-too` (Ала-Тоо: день рождения/юбилей/кыз узатуу), `tunduk` (Түндүк: золото на тёмном,
  юбилей/свадьба), `beshik` (Бешик: детские тои), `neon` (Неон: вечеринки, билет-обложка). Первые четыре — только тема и украшения: `cream-classic` (Кремовая классика), `rose-garden` (Розовый сад), `golden-autumn` (Золотая осень),
  `starry-night` (Звёздная ночь). Следующие три собраны на новых возможностях (виды блоков, заставки, векторные
  ассеты, CSS-фоны, PRO-шрифты): `eucalyptus` (Эвкалипт), `art-deco` (Великий Гэтсби, палитра `noir`),
  `lavender-provence` (Лавандовый Прованс, палитра `lavender`); `marble-olive` (Мрамор и олива) удалён (его фикстура
  `1.0.0-template-marble-olive.json` остаётся). Шаблон = полная
  `theme` + оформление блоков по типам (`variant/surface/surfaceOpacity/ornaments/entrance`) + `dresscodeColors`.
  Картинки берутся по id из `library` (`lib(id)` бросает ошибку на несуществующий id).
  Последние четыре — по мотивам примеров с Pinterest (next-blocks.md), **со своей структурой** (`layout`: блоки по
  порядку с примером текстов, фото и оформлением): `boarding-pass` (Посадочный талон: `navy`, обложка `ticket`,
  кремовые «билеты» = карточка + `bgColor` + край `perforated`, ч/б фото), `lago` (Итальянское озеро: `sand`,
  рукописные заголовки `headings: names`, полосы `bgColor` с рваными краями, фото с рваными краями), `mocha` (Шоколад
  и сургуч: свой фон `#2b1f18`, узор «Стена», обложка `monogram` на креме с рваным низом, кремовые `#ffeddb` полосы и фото с
  рваными краями, цитата на шёлке, галерея, сургуч — по приглашению владельца), `seaside` (Морской берег:
  `pearl`, обложка `cover`, ракушка, жемчуг, розы), `emerald-night` (Изумрудная ночь, 1.2.0: палитра `forest` + свой фон `#061e10`, узор «Точки»,
  фото пары в лесу и беседки у пруда — от пользователя, лицензия уточняется; украшения-переходы (`seam`) — гирлянды шиповника и белые розы на стыках, светлая бумага `PAPER` с рваными краями среди
  тёмных блоков; по мотивам промо-ролика, свои фото и тексты), `etno` (Этно, 2.4.0: перенос первого сайта владельца
  toigokel.kg/templates/toigokel-etno, все картинки и ролик — его, «Собственность проекта»; палитра `burgundy`,
  видео-конверт с сургучом-юртой, обложка `scene` (кадр видео обложки), угловые узоры `etno-corner`, бордовые полосы
  `BORDO` = цвету волн-разделителей `etno-divider-*` (переходы `seam` размера 400; у картинок прозрачная половина, чтобы
  прямой край лёг на стык, а волна — на соседний блок), календарь «Неделя» на карточке `card-etno`, анкета `choices`,
  финал — «Текст» с фото колец фоном; тексты — русские из его конфига, музыка — «Эрке Сары»: трек комуза с его сайта
  не переносили — права не уточнены). Фото-примеры — `photo(id)` → `/templates/<id>.webp`.
  Проверено на практике: золотая акварель `wc-gold` и шторки `curtains` на тёмной палитре выглядят грязно;
  украшения `top` у блока с заголовком налезают на него — лучше углы/бока/`bottom`.
- У шаблонов без своей структуры — `heroPhoto` (фото обложки, `public/templates/<id>-hero.webp`, взяты с toichakyru.com —
  сайт владельца проекта; три с пометкой «уточняется» в CREDITS.md) и `heroNames`: в примерах кыргызские и казахские
  пары (Айгерим & Нурлан, Айпери & Бакыт…), у шаблонов со структурой — свои имена в `layout`. `sampleBlocks` ставит их
  в главный экран, если структура не задаёт своё.
- `createFromTemplate(t)` — новое приглашение с примером текстов (`sampleBlocks(t)`: структура шаблона или стандартный
  набор; id «b-<тип>», повторы «b-<тип>-2»).
- `applyTemplate(data, t)` — **чистая** функция: меняет тему (кроме `background`) и оформление блоков (`BlockDesign`:
  вид, фон, **цвет фона**, прозрачность, края и их зёрна, ширина, украшения, появление, **стили надписей**), цвета
  дресс-кода; сохраняет имена, дату, тексты, программу, фото и фоновые картинки, музыку, набор и порядок блоков,
  видимость, заголовки. Оформление n-го блока типа — из n-го блока этого типа в `layout` (лишние — последнего), иначе
  из `blocks` по типу, иначе «классика, без фона, без украшений». Блоки, которых в шаблоне нет, шаблон не добавляет.
  Тема копируется `structuredClone` (`themeOf`, по умолчанию `headings: "caps"`) — иначе вложенные `decor/envelope`
  были бы общими с константой шаблона и мутировались.
- Главная (`TemplateGallery`, карточка — общий `TemplateCard`, стиль — по мотивам toichakyru.com/templates): карточки 4:5, скругление 24–28 px, на телефоне — одна в ряд, мягкая тень, подъём при наведении; снизу лёгкий градиент + размытие с маской, подпись-настроение (первая фраза описания) и название Playfair (полное описание — только для
  скринридеров); вся карточка — прозрачная кнопка поверх превью, «Выбрать» появляется при наведении/фокусе (только
  `pointer-fine`), на телефоне карточку просто нажимают. «Выбрать» → окно «Главное о событии» (`SetupDialog`: имена,
  дата + время (16:00), место, песня из `musicTracks` с «Послушать»; на компьютере — окно, на телефоне — весь экран) →
  `POST /api/invitations {template, setup}` → `window.location.assign(editUrl)`. «Пропустить» — без `setup` (пример
  текстов шаблона). `setup` проверяет `setupSchema` и кладёт в приглашение `applySetup` (`lib/setup.ts`; это не формат
  приглашения — версию не трогает). Пустое место не затирает пример шаблона.
- Редактор («Оформление» → «Шаблон»): мини-превью, подтверждение через shadcn `AlertDialog`.
- `TemplatePreview` рендерит настоящий `InvitationView` (только hero, 390×700) и масштабирует `transform: scale`;
  `inert` + `aria-hidden`. В превью есть свои кнопки, поэтому кликабельная плитка сделана **прозрачной кнопкой
  поверх превью**, а не обёрткой (вложенные `<button>` = hydration error; есть регрессионный тест).
